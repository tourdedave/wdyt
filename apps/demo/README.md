# WDIT Demo App

Controlled demo target for WDIT.

Included flows:

- Login success to protected pages
- Login validation error without navigation
- Search with results vs empty state
- Small SPA workspace section using `history.pushState`

Run:

```bash
cd apps/demo
npm run build
npm start
```

Default URL:

```text
http://127.0.0.1:4010
```

- username: `demo`
- password: `password`
